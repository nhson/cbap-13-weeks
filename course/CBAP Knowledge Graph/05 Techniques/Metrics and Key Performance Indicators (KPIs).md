# 10.28 Metrics and Key Performance Indicators (KPIs)

> [!abstract] In a nutshell
> Indicator = numerical measure of progress; metric = quantifiable level; KPI = indicator of progress towards a strategic goal. Good indicators: clear, relevant, economical, adequate, quantifiable.
