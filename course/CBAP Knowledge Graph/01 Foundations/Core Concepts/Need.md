# Need

> [!quote] Definition (in our words; see BABOK 2.1)
> A problem to solve or an opportunity to pursue.

A need can trigger change by prompting stakeholders to act. A change can also create new needs when it raises or lowers the value of existing solutions.

**Ask:** *Which problem or opportunity are we addressing?*
