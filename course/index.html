Course: CBAP in 13 Weeks

Sep 27, 20265 min read

Seventy-five interactive lessons across 9 modules and 13 weeks at about 10 hours a week. Each lesson follows teach → apply at GreenBasket → exam drill → wrap-up.

Two ways to use it

  • Read every lesson on this site.
  • Be taught by Claude: clone the repository, cd course, run claude, type /start 1.1, and then use /next, /progress, /drill and /grade.
